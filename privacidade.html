Política de Privacidade

Última actualização: Setembro de 2026

1. Introdução

A tua privacidade é importante para nós. Esta Política de Privacidade explica como o Fitgram recolhe, utiliza, armazena e protege os teus dados pessoais, em conformidade com o Regulamento Geral sobre a Protecção de Dados (RGPD) da União Europeia e a legislação portuguesa aplicável.

Responsável pelo tratamento de dados:
Matheus Carelli Rangel
Trabalhador independente, Portugal
Contacto: disponível na secção de Suporte dentro da App

2. Dados que Recolhemos

2.1 Dados que forneces directamente

  • Dados de conta: email, palavra-passe (encriptada), nome, username
  • Dados de perfil: foto de perfil, foto de capa, bio, data de nascimento, género
  • Dados de fitness: peso, altura, idade, objectivos de treino, nível de actividade física
  • Conteúdo publicado: fotos, vídeos, comentários, mensagens

2.2 Dados recolhidos automaticamente

  • Dados de utilização: interacções, histórico de treinos, tempo de sessão
  • Dados técnicos: tipo de dispositivo, sistema operativo, versão da App

2.3 Dados que não recolhemos

  • Não recolhemos a tua localização GPS
  • Não acedemos aos teus contactos
  • Não recolhemos dados de navegação fora da App

3. Como Usamos os Teus Dados

  • Fornecer o serviço: criar e gerir a tua conta, mostrar o feed, processar publicações
  • Personalizar a experiência: gerar planos de treino e alimentação adaptados ao teu perfil
  • Sistema de gamificação: calcular XP, níveis, ranks e conquistas
  • Publicidade interna: mostrar publicações patrocinadas relevantes (sistema de Boost)
  • Segurança: detectar e prevenir fraudes, abusos e violações dos Termos
  • Melhoria do serviço: análise de utilização de forma agregada e anónima

4. Base Legal para o Tratamento

  • Execução do contrato: para fornecer os serviços que solicitaste
  • Consentimento: para funcionalidades opcionais
  • Interesses legítimos: para segurança e melhoria da plataforma
  • Obrigação legal: quando exigido pela lei portuguesa ou europeia

5. Partilha de Dados

Não vendemos os teus dados pessoais a terceiros.

Partilhamos dados apenas com:

  • Supabase: base de dados e autenticação, em conformidade com o RGPD
  • Apple / Google: processamento de pagamentos via App Store e Google Play
  • Autoridades competentes: quando exigido por lei ou decisão judicial

6. Armazenamento e Segurança

Os teus dados são armazenados em servidores seguros. Implementamos medidas técnicas e organizacionais para proteger os teus dados contra acesso não autorizado, perda ou destruição. A tua palavra-passe é sempre armazenada de forma encriptada.

7. Retenção de Dados

  • Dados de conta activa: mantidos enquanto a conta estiver activa
  • Dados de utilização: até 12 meses
  • Após eliminação de conta: dados pessoais eliminados no prazo de 30 dias
  • Dados de pagamento: conforme exigido pela legislação fiscal portuguesa

8. Os Teus Direitos (RGPD)

  • Acesso: podes solicitar uma cópia dos teus dados pessoais
  • Rectificação: podes corrigir dados incorrectos no teu perfil
  • Eliminação: podes solicitar a eliminação da tua conta e dados ("direito a ser esquecido")
  • Portabilidade: podes solicitar os teus dados num formato legível por máquina
  • Oposição: podes opor-te ao tratamento para fins de marketing
  • Limitação: podes solicitar a limitação do tratamento dos teus dados

Para exercer os teus direitos, contacta-nos através do email de suporte disponível na App. Responderemos no prazo de 30 dias.

Tens também o direito de apresentar reclamação à Comissão Nacional de Protecção de Dados (CNPD): www.cnpd.pt

9. Conteúdo Público e Privado

  • As tuas publicações são públicas por defeito
  • Podes tornar a tua conta privada nas Definições
  • As tuas mensagens directas são privadas e apenas visíveis para ti e o destinatário
  • Os teus dados físicos (peso, altura, medidas) são sempre privados

10. Menores

O Fitgram não é destinado a menores de 13 anos. Se tomarmos conhecimento de que recolhemos dados de uma criança com menos de 13 anos sem consentimento parental verificável, eliminaremos essa informação imediatamente.

11. Cookies e Tecnologias Similares

A App utiliza armazenamento local (AsyncStorage) para guardar preferências e sessão de forma segura no teu dispositivo. Não utilizamos cookies de rastreamento de terceiros.

12. Alterações a Esta Política

Podemos actualizar esta Política de Privacidade periodicamente. Quando o fizermos, notificaremos os utilizadores através da App sobre alterações significativas.

13. Contacto

Para qualquer questão relacionada com privacidade ou para exercer os teus direitos, contacta-nos através do email de suporte disponível na secção de Suporte dentro da App.
